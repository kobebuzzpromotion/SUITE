## Remaining limits / open items

- Real licensed RAW import→proxy→person analysis→edit→save→reload→fresh fixed Final is **NOT_RUN**. All RAW-like filenames in Node state fixtures contain explicitly NON_RAW bytes and use a fake decoder. They cannot be evidence of supported cameras or RAW quality.
- Face oval masks are not person-instance segmentation and do not prove that every visible person was detected. Actual one/two/three-plus people, occlusion, overlap, background protection, halo, Proxy/Final intent and alpha/color quality require real fixtures.
- An already-saved neutral photo without a cached or current portrait inventory is currently denied first analysis with `HISTORICAL_PERSON_INVENTORY_UNAVAILABLE`. This is a conservative availability limitation (current endpoint does not expose historical inventory), not a complete first-analysis/recovery workflow. Do not bypass the safety guard without an authoritative history strategy.
- A server-accepted save followed by local cache persistence failure retains unsaved state but may require explicit conflict/recovery handling; durable conflict-resolution UX and Original orphan Recovery remain separate unfinished work.
- Rendering caps (128MiB input, 24MP pixels), schema checks and mocked QuotaExceeded errors are not measured peak-memory, actual out-of-memory, thermal or device-capacity tests. Web author authentication/submission, production Auth/Cloud/Sync/Billing and invitation/public launch are not validated.
- Web engine is `web-libraw-mediapipe-face-exposure-1`, distinct from Apple. Swift continues to reject unknown engine; cross-platform portrait rendering is unsupported/unverified. Original Recipe envelope and network routes were reused; no new DB/HTTP schema was introduced by this reviewer.
- Latest Web Node51 is separate from the frozen Windows154 baseline. Apple112 remains **NOT_RUN**. Real-image/RAW parity and Mobile Release remain **BLOCK**. Browser/UI results must be supplied separately by main and never inferred from this report.

Owned edits only: `apps/web/tests/**` and this report. No production source, original audit, fixed147, frozen Evidence or other agent's file was edited.
