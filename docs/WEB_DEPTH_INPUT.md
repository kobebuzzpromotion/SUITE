# 手持ち深度データの入力

AIを使わず、写真全体に対応する深度をJSONで読み込む。画像ファイルやメーカー独自の深度形式を自動変換する入口ではない。

必須フィールド（追加キー不可）:

|キー|値|
|---|---|
|schemaVersion|1|
|sourceSHA256|元RAWファイルのSHA-256、小文字64桁|
|sourceWidth / sourceHeight|向き補正後・切抜き前の原寸画素数|
|width / height|深度グリッドの幅・高さ、積は65,536以下|
|data|幅×高さ個の数値。near=0、far=1、左上から行優先|
|validity|同じ点数の0/1。0は深度不明、1は有効|

入力2MiB以下。深度は写真全体と対応し、Crop・回転・変形を焼き込まない。欠測はvalidity=0で表す（data自体には有限の0〜1値が必要）。欠測部分は範囲反転時も除外する。自動推定、欠測の補完、写真の送信は行わない。

読込み時に原本SHAと原寸寸法を照合し、利用者が対応を確認した後だけ適用できる。選択範囲は近側フェード開始・全適用開始・全適用終了・遠側フェード終了の4値（昇順）。範囲内の露出・コントラスト・彩度を調整する。

深度と調整値を写真固有Recipeへ保存し、Undo・比較・復元・Preview・通常Finalで再使用する。全Recipeの別写真Batchコピーや可搬Presetへの混入は拒否する。処理は幾何変換前で、既存Crop・回転・変形と一緒に出力へ移る。

実処理frameは既存24MP以内。原寸metadata96MPの受理は96MP書出し対応を意味しない。ビルド確認と実写真の品質確認は別。
