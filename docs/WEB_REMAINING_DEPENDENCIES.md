# 通常Webの残る依存条件

2026-10-09。コード作成と実画像の動作確認は別。AI、テザー/SDK、Apple、HDR、大判はユーザー指定で保留。

|対象|現在使える部分|残る条件|
|---|---|---|
|LUT|ローカルCUBE、局所適用、同梱Preset|ユーザー指定はローカル運用。クラウド同期は今回の残作業に含めない|
|書出しPreset|端末内設定保存・再適用|Workspace共有は別機能。実principal/tenantとAPI接続は次回以降|
|Proxy同期・容量|端末内保存、接続先による保存記録表示|実ストレージprovider、ACL、容量契約、転送経路が必要。Cloud Safeを捏造しない|
|個人Look|1〜200組JPEG/PNGまたはRAW→JPEG/PNGの逐次全体色学習・保存・適用|実画像確認はユーザー。RAWは実原寸sRGB8現像8MPまで。CFA学習・大型RAWは含まない|
|旧人物補正の一括出力|写真ごとの明示同意・保存版/SHA/人物ID照合付き保存済み5メイクBatchを配備済み|実画像確認はユーザー。非中立portraitの人物推論はAI保留|
|旧BW/背景影の保存版・Batch|ユーザー承認のlocal専用同意/実同DB原本・背景/保存文書照合で再適用経路を配備|実画像確認はユーザー。原寸8MPまで、新規authoringと未定義混在は含まない。別保存先の原本/権限は別途必要|

クラウド機能は接続先・実認証の提供前に完成とはできない。プレビュー用Cloudflare workerに勝手に本番DB/R2/認証を追加しない。既存ローカル機能をクラウド同期の代わりとして完成計上しない。
