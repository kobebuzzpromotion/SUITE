# Mobile cross-source semantic correspondence

Reviewed 2026-10-03. Audit-only evidence; original `mobile_tether` and `index_reverse` reviews remain frozen.

## Coverage

The existing 108-article / 1,949-fact Mobile+iPad+tether review was compared with the 25 visible US and JP App Store version entries (3.3.3 through 2.5.5) and the complete official MOBILE page. The review splits 47 named release operations/plan statements per region and 21 Mobile-page statements.

141 source-key-to-external-locator mappings reference 75 existing fact keys: 70 `SAME_OPERATION`, 71 `RELATED`. Remaining 1,874 keys have no explicit correspondence in this narrow external-source set; this is not proof of absence. All source keys are accounted for by article in the JSON.

## Meaning of the relations

- `SAME_OPERATION` means the same explicit operation is named. It does not transfer subcontrols, device scope, region, plan, credits, processing location or file constraints.
- `RELATED` means a family, possible rename, broader platform claim or related workflow only. It is not an alias merge.
- Unmatched named release operations retain an explicit reason. Generic bug fixes, performance improvements, audience/outcome claims and footer links cannot identify a unique editor control.

Every visible version has a disposition; every Mobile heading is covered by either specific statements or promotion/navigation reasons. User ratings/reviews are excluded as non-developer evidence.

## Important unresolved correspondence

Tier-dependent free color exports in App Store 3.2.5 contradict S21313’s Desktop-only / Mobile-unavailable subscriber benefit. Both claims remain. No free allowance, plan or regional reconciliation is invented.

A creative Effect named Golden Hour is not automatically Relight Golden Hour. Sunset Glow versus Golden Hour relighting is a possible label change, not a confirmed alias. A shadow alignment anchor is not AI Retain Shadow, and a system share sheet is not an Online Gallery / QR-card export.

The older Mobile overview links web AI tools. The newer App Store AI eye-opening, restoration, colorization, enhancement and people-removal claims are related mentions, not proof of native execution or processing location. Japanese store description mentions local/cloud generally, not per operation.

The JSON preserves 28 named-operation candidates in `newFeatureCandidates`, including unresolved related identities. These are source-claim candidates for the parent’s Registry decision, not 28 new unique features or added SUITE specifications. Combined App Store iPhone/iPad product compatibility does not establish every release operation on both platforms.
