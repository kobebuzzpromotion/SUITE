## Original subitems and meaning

The [official Color Adjustments guide](https://support.evoto.ai/color-adjustment-feature-modules/) lists nine color ranges (Reds, Yellows, Greens, Cyans, Blues, Magentas, Whites, Neutrals, Blacks), four CMYK sliders within the selected range, and Relative/Absolute methods. It states slider bounds of `-100..100`, describes Relative as proportional and Absolute as direct, and explicitly says all nine channel adjustments can be batch-synchronized and saved in presets. Its text does not specify exact masks, RGB/CMYK conversion mathematics, gamut behavior, or reference pixel outputs. The [feature tree](EVOTO_AUDIT/EVOTO_FEATURE_TREE.md) records **15 subitems**: nine ranges (EV3-0501–0509), four shared controls (EV3-0510–0513), and two methods (EV3-0514–0515); it does not assert 36 separately named features.

| Subitems | Current SUITE implementation | Evidence / remaining boundary |
| --- | --- | --- |
| EV3-0501–0506: six hue families | `reds`, `yellows`, `greens`, `cyans`, `blues`, `magentas` | Nine-option Editor range selector and real SUITE sRGB8 processor; six hues have bounded per-range weights. |
| EV3-0507–0509: three tone families | `whites`, `neutrals`, `blacks` | Same selector/processor, with SUITE-owned tonal masks. These are not printer CMYK separations. |
| EV3-0510–0513: four sliders | `cyan`, `magenta`, `yellow`, `black` under the selected range, integer `-100..100` | Every 9×4 pair validates and changes a matching synthetic sample in [new audit test](../apps/web/tests/selective-color-completion-audit.test.mjs). This is not 36 real-Chrome interaction proofs. |
| EV3-0514–0515: two methods | `relative` default (omitted Recipe key), `absolute` explicit key | Both produce distinct pixels on a synthetic midtone; the existing real-Editor fixture saves/reloads and Undo/Redoes a method switch. |

SUITE's [processor](../apps/web/src/processing/selective-color.mjs) is a deterministic display-referred RGBA8 design using its own hue/tone weights and additive CMYK-direction changes. It explicitly disclaims Evoto/Photoshop pixel equivalence and ICC print conversion. Neutral settings detach but preserve pixel bytes, alpha and fully transparent hidden RGB remain intact, and malformed values/unknown keys/abort fail closed. Do not infer the external product's exact formula from its control labels.
