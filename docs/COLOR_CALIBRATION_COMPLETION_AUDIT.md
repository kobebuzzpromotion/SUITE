## Source boundary and six subitems

The [official desktop Color Adjustments guide](https://support.evoto.ai/color-adjustment-feature-modules/) and [mobile Color guide](https://support.evoto.ai/color-adjustments-module/) describe changing Hue and Saturation for Red, Green, and Blue primary channels to correct or style color. The text does not publish exact parameter ranges, color profile stage, transfer function, matrix, or numerical pixel formula. The existing [feature-tree rows](EVOTO_AUDIT/EVOTO_FEATURE_TREE.md) enumerate the six operations below. The separate “Color Calibration” label under Personalized AI Look (EV3-0612) is **not** this manual six-control group.

In full, the save location is `parameters.extendedParameters.postDecodeAdjustments.color.calibration`. Each SUITE value is an integer `-100..100`; zero is neutral. [The pure processor](../apps/web/src/processing/color-calibration.mjs) is SUITE's deterministic, display-referred linearized-sRGB primary transform. It does not change RAW-stage camera calibration, DCP profiles, or Original bytes, and cannot be represented as pixel-equivalent to the source product from the official description alone. The renderer places calibration after global color and before Selective Color/Levels/Curves/Glow/Detail/Grain ([render pipeline](../apps/web/src/processing/pure.mjs)).
